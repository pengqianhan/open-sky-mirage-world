## 2026-11-05 Q 版重制

- 几何：曲面统一经样条细分，接缝放到背面并焊接法线，消除脸部竖向硬线和袖子棱面；发束改为带圆头的片状，刘海按人物区分。

- 适配：骑手座高、铁索悬挂点（新增两条牵绳）、飞鸢翼梁、步行跟随镜头和图鉴取景都改为读取角色尺寸。

## 2026-11-05 攻击动作

六位主演各有一招，步行模式下按 F / J 或触屏「攻」键出招，图鉴动作列表新增「攻击」循环预览。关键帧在 `js/lead-attacks.js`，轨迹和气浪等特效在 `js/lead-attack-fx.js`。

| 主演 | 招式 | 表现 |
| --- | --- | --- |
| 曹晟 | 推云掌 | 蓄势转身、上步推掌，掌心蓄光并推出三层气环 |
| 曾倩 | 飞羽穿云 | 从背后取弓、侧身拉满、放箭，弓弦随手形变，放箭后回弹 |
| 封不害 | 崩山棍 | 单手抡棍过顶，左手接杆下砸，地面起两圈震波 |
| 芸娘 | 流萤交剪 | 从肩后拔出背负的双弯刀，跃起连斩成 X，收招时插回背后 |
| 谢景棠 | 匣中飞针 | 抬匣至胸前，匣门滑开露出针孔，连发两轮扇形飞针 |
| 林寒 | 寒月横扫 | 长刀后引，滑把横扫半圈，留下月牙形刀光 |

- 手臂用两骨 IK 追手部目标，武器放在目标上，所以握持不会随身体转动而漂移。特效是攻击时间的纯函数，图鉴循环和游戏内表现一致。
- 出招时双脚定住，不能移动和转向；过了 `cancelAt` 后可用移动打断收招。按住可连招，短于一帧的点按也不会丢。
- 音效是滤波噪声合成，随声音开关；放箭、下砸等命中时刻触发。

### 验证

- `npm run test:characters` 增加：攻击中双手与目标误差小于 0.02、脚不入地、腿不穿裙（每招多帧采样）、结束后武器和隐藏件复位、快速点按生效、出招定身、移动打断、切模式取消、骑乘不触发。
- `npm run build`、`git diff --check` 通过。
- 编辑器预览实测：用逐帧对照页看过六招；真实按键出招（曹晟、曾倩、封不害）；图鉴「攻击」（林寒，以及 390×844 下的芸娘）；390×844 触屏「攻」键（曹晟）。未见控制台报错和资源加载失败。

### 未覆盖

- 攻击目前只是表现：没有判定、伤害和受击，街上行人和城内武士不会反应。
- 只在步行模式可用；策马、铁索和飞鸢中按键不触发。
- 手臂、武器与衣饰、头发之间没有自动穿插检查，只覆盖腿与主裙体。
- 音效未经人耳试听，只确认了代码路径和测试中的触发次数。
- 第一人称和低角度机位下未看过招式效果；未在实体手机上测性能。切换角色后首次渲染会有一段着色器编译卡顿，这段时间内的方向键可能没有效果，本次未改动。

## 2026-11-05 芸娘双刀改为背负

- 刀鞘从腰侧移到后背，交叉背负：刀柄在肩后，刀尖交于后腰。刀鞘加长并做成弯形，和拔出的弯刀对得上；左右镜像，刀刃都朝外。
- 流萤交剪时长由 1.35 秒改为 1.55 秒，命中点由 0.4 秒推迟到 0.5 秒：多出伸手到肩后、拔刀外甩、收招插回三段。
- 宽袖在肘部补了圆角，手臂折得很紧时不再露出袖管断口。
- `npm run test:characters` 新增两项：拔刀和还鞘瞬间，手的位置与刀的朝向都要和鞘中对齐；刀鞘不进入身体和裙子。
- 实测：逐帧看过正面、侧面、背面的拔刀、连斩和还鞘，以及行走、奔跑、骑乘、抓索、御风时的背负状态。在游戏中按 F / J 出招，确认手搭上刀柄、挥砍、收招后刀回到背上；图鉴背面正常。未见控制台报错。

### 未覆盖

- 拔刀时有几帧刀身从鞘侧穿出，而不是沿鞘口完整抽出。刀比手臂能拉开的距离长，这里靠动作速度带过。
- 刀鞘只检查了身体和裙子，手臂、发辫与刀柄之间未自动检查。收招阶段用移动打断时，刀会直接回到背上，没有还鞘动作。
- 未在实体手机上测试。

### 发现但未改动

- 曾倩取弓时，手的目标点与弓的静止位置相差约 0.11 个角色单位，弓会瞬移一小段。
